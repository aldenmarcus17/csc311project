\subsection{Softmax regression}
Softmax regression is the linear baseline for the three sport classes. It combines the 73 numeric, ordinal and fixed binary predictors into class scores, then converts them to probabilities with softmax. A compact linear model suits the limited respondent count and provides a comparison with nonlinear tree models. The implementation uses scikit-learn 1.7.2 multinomial logistic regression with L2 regularization, an intercept, no class reweighting and the L-BFGS optimizer. The stopping tolerance is 1e-6 and the initial iteration cap is 1,000. A predeclared convergence warning rule retries the same setting once with a cap of 5,000; unresolved fits cannot win tuning.\cite{sklearn_logistic}

Within each outer training partition, grid search compares C = 0.01, 0.1, 1, 10 and 100 using mean accuracy across its three recorded inner folds. C is inverse regularization strength; the grid spans strongly to weakly regularized models. Accuracy ties within 1e-12 favor smaller C. The predeclared expansion rule adds exactly one candidate, 0.001 or 1,000, if the initial winner is at the corresponding boundary. Outer-fold scores are not used to select C. The five numeric or ordinal predictors are standardized with training means and population standard deviations; the 68 binary flags remain 0/1. Preprocessing is fitted separately on every training partition.

This run completed 75 initial inner-search fits, 0 expansion fits and 5 outer refits (80 fit attempts total), with 0 convergence retries and 0 unresolved inner failures. Selected C values for outer folds 0-4 were 1, 1, 1, 1, 0.1. All initial winners were inside the search bounds, so no expansion was needed. The tuning curves document the regularization trade-off instead of comparing defaults alone.
